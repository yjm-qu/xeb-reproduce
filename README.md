# XEB 量子优越性实验复现

基于 uniqc 代码库复现 Sycamore 量子优越性实验（XEB）。

## 实验参数
- 量子比特数：n = 20
- 循环数：m = 20
- 采样数：N_s = 10^4
- 重复次数：K = 1
- 单门错误率：ε_1 = 0.0016
- 双门错误率：ε_2 = 0.0062

## 使用方法
无噪声：
```
python xeb_v2.py
```

含噪：
```
python xeb_v2.py --noise
```

## 实验结果
- 无噪声 F_XEB ≈ 1.0
- 含噪 F_XEB ≈ 0.2（理论 α_f = 0.227）
